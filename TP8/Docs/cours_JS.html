1. Structure de base d'un programme

[cite_start]

Lorsque le code JavaScript se trouve dans un fichier séparé (.js), la structure est la suivante[cite: 498, 530]:

/* zone d'en-tête */
/* déclaration des variables globales */
/* définition des fonctions (function) */
/* CORPS DU PROGRAMME (Instructions) */
/* FIN */
[cite_start]

Dans une page Web, on utilise la balise <script> insérée entre <head> (pour le global/fonctions) ou <body> (pour les instructions)[cite: 527, 528, 529].

2. Les Commentaires

    [cite_start]
  • // : Commentaire sur une seule ligne[cite: 545].
    • [cite_start]
  • /* ... */ : Commentaire sur plusieurs lignes[cite: 546, 547].
[cite_start]

Un bon commentaire doit expliquer l'utilité d'une variable ou d'un bloc, et non paraphraser le code[cite: 554, 556].

3. Déclaration des Variables

[cite_start]

JavaScript est un langage faiblement typé : on ne précise pas le type à la déclaration, il est fixé à l'utilisation[cite: 570, 576, 577].

    [cite_start]
  • let : Déclare une variable à portée locale (recommandé)[cite: 634, 637].
    • [cite_start]
  • var : Déclare une variable à portée globale[cite: 632].
    • [cite_start]
  • const : Déclare une constante qui doit être initialisée immédiatement[cite: 639, 640].

5. Opérateurs Arithmétiques

[cite_start]

Priorités identiques aux mathématiques[cite: 454]. [cite_start]Opérateurs disponibles : +, -, *, /, % (modulo), ** (puissance)[cite: 455].

[cite_start]

Note : JavaScript tente toujours de retourner un résultat, même illogique (ex: 5 / "test" donne NaN)[cite: 457, 458].

6. Opérateurs Logiques et Affectation

  • Logique : == (égal), != (différent), && (ET), || (OU), ! (NON).
  • Incrémentation : i++ (après), ++i (avant), i--.
  • Conditionnel : k = condition ? val1 : val2 (Ternaire).

7. Fonctions d'Entrée/Sortie

  • window.alert(message) : Affiche un message.
  • window.confirm(message) : Retourne true (OK) ou false (Annuler).
  • window.prompt(message, defaut) : Retourne la saisie de l'utilisateur ou null.
